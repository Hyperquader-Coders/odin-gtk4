# Spec: odin-gtk4

## Packages

```
gtk4/   package gtk4: generated by runic from gtk4/rune.yml
gdkx/   package gdkx: GDK's X11 backend, generated by runic from gdkx/rune.yml
```

Import through the `gtk4` collection: `import "gtk4:<package>"`.

## Surface

Every public declaration of the bound headers (GTK 4, GDK and GSK 4.16.13), named as runic names
them, plus the hand fixes in [PATCHED.md](PATCHED.md). `gdkx` is `gdk/x11/gdkx.h`: the `gdk_x11_`
prefix is gone (`gdk_x11_surface_get_xid` is `gdkx.surface_get_xid`), GDK's types are `gtk4`'s
(`^gtk.Display`) and Xlib's are odin-x11's (`x11:xlib`: `xlib.Window`, `^xlib.Display`), the suite's
one Xlib binding. Deprecated API is bound, because
`GLIB_DISABLE_DEPRECATION_WARNINGS` is set when generating.

## Version

The binding records the library version it was generated from (README). `make test` compares
it with the header macros and with the loaded library; DECISIONS §3 sets the rules.
